# Sentient Alignment

## Positioning

OpenCare Proof Kit should be submitted as open-source infrastructure for trustworthy, private health AI agents.

## Alignment

| Criterion | Project fit |
|---|---|
| Open | code, schemas, evidence-pack format, safety policies and evals are open |
| Accessible | local Docker/CLI workflow, no required cloud account |
| Private by default | raw health/genetic data remains local in v0.1 |
| Empowering | users keep and inspect their data and outputs |
| Public good | reusable trust layer for health-agent builders |
| Infrastructure | deterministic tools, evidence packs, safety policy, audit trail and evals |

## Grant angle

Primary angle:

> The infrastructure that makes private health agents trustworthy.

Reference demo:

> Medication-to-Doctor Briefing from synthetic/demo health vault and genotype-like data.

## Roadmap alignment

Later roadmap can include:

- confidential compute adapter;
- remote private inference;
- broader health-agent workflows;
- clinician workspace;
- Sentient ecosystem integration if official docs and APIs support it.

Do not invent Sentient APIs or integration requirements. Verify official sources before implementation.
