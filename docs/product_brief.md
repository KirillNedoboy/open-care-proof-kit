# Product Brief

## Product

OpenCare Proof Kit is an open-source, local-first toolkit for building private, evidence-grounded health AI agents.

## Reference workflow

Medication-to-Doctor Briefing: a synthetic/demo workflow that generates a clinician-reviewable medication discussion briefing from structured health context, genotype-like data, evidence packs, deterministic rules, safety policy, and LLM report writing.

## User

Primary users for v0.1:

- open-source AI builders;
- privacy-focused users with sensitive health/genetic data;
- clinicians/pharmacists/genetic counselors evaluating future health-agent workflows;
- grant reviewers evaluating trustworthy health-agent infrastructure.

## Pain

Users have sensitive health/genetic data, but the current options are weak:

1. Upload to closed cloud tools.
2. Ask a generic LLM and risk hallucinations.
3. Manually read fragmented medical/genetic sources.

## Core benefit

A local, auditable, source-cited health-agent pipeline that makes sensitive health AI workflows safer and inspectable.

## Non-goals

No diagnosis, dosage advice, treatment recommendation, real patient data, FASTQ/WGS pipeline, SaaS, auth, payments or Telegram in v0.1.
