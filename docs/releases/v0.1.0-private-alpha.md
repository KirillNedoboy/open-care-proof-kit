# OpenCare 0.1.0 private-alpha release candidate

## Release status

Candidate only: local-first, controlled private alpha. No tag or public release
has occurred. This is not production-ready and not clinically validated.

## What is included

- Persistent People; Medication sources, CandidateFacts, review, canonical
  records, and Timeline events.
- Visits, Questions, persisted editable Visit Brief revisions, and deterministic
  Person vault export.
- Operator-only installation `backup`, `verify`, read-only `preflight`, and
  fail-closed `recover` to an absent or empty target.
- Product Core Workspace UI, wheel-packaged runtime assets, constrained Python
  3.12 dependencies, and explicit production Compose Product Core persistence.

## What is not included

- Diagnosis; dosage or start/stop medication recommendations; clinical
  validation.
- Identity or per-Person authorization; caregiver access controls; encryption at
  rest.
- Import/merge, cloud backup, hosted SaaS guarantees, OCR/broad ingestion,
  genetics or PGx expansion, or Sentient runtime integration.

## Data and privacy boundary

Sensitive data remains operator-controlled. Exports and backups are plaintext
sensitive artifacts. Backups exclude credentials, secrets, cookies, TLS
material, and deployment configuration. Development/demo Compose is not
appropriate for sensitive private-alpha data. The installation-wide password
gate is not per-Person authorization.

## Known limitations

- Docker container recreation smoke has not been executed.
- One existing Starlette/httpx deprecation warning remains.
- Recovery makes no crash- or power-loss guarantee between filesystem operations.
- Windows acceptance is verified; Linux CI is verified, but production
  Linux/Docker runtime is not overstated.

## Validation baseline

Prior accepted evidence from the implementation baseline
`874c44d1308e016c68c58bf257a29a26eea746f6` records 304 pytest passes, Ruff,
mypy for 65 files, 14/14 evals, trust metrics, constrained Python 3.12
installation, non-editable wheel startup, and production Compose configuration
validation. Docker recreation was not executed because the engine was
unavailable.
